# Finnish School Robotics

## What is Robotics?

Robotics is the study of **robots** and how they work. Robots are machines that can follow instructions and complete different tasks.

## What is a Robot?

A robot is a machine that can be programmed to perform actions. Some robots use *sensors* to understand their surroundings.

## How Does mBot2 Work?

mBot2 is an educational robot that we use in ICT lessons. It has motors, sensors and a programmable controller called CyberPi.

## Important Parts of a Robot

1. Sensors - detect information.
2. Motors - help the robot move.
3. Controller - processes instructions.
4. Battery - provides energy.

## Why is Programming Important?

Programming tells robots what to do. We can use Python and mBlock to create instructions for mBot2.

## Examples of Robots

- Industrial robots in factories.
- Medical robots in hospitals.
- Educational robots in schools.
- Cleaning robots in homes.

## What I Learned

I learned that **robotics combines technology and programming**. Using mBot2 helped me understand how robots follow commands and use sensors.
